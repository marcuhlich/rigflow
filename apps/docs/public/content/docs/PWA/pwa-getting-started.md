# Getting started

RigFlow ist als **Progressive Web App (PWA)** verfügbar. Das bedeutet: Du kannst die App wie eine native App auf deinem Smartphone oder Tablet installieren – ohne App Store, ohne Download-Wartezeit.

---

## Was ist eine PWA?

Eine Progressive Web App ist eine Webseite, die sich wie eine native App verhält. Sie kann auf dem Homescreen installiert werden, hat ihr eigenes App-Icon und läuft ohne Browser-Adressleiste – genau wie eine normale App.

**Vorteile gegenüber einer nativen App:**

- Keine Installation über App Store / Google Play nötig
- Immer aktuell (Updates im Hintergrund)
- Funktioniert auf Android **und** iOS
- Geringer Speicherbedarf

## Offline-Funktionalität

Die PWA speichert wichtige Daten lokal auf deinem Gerät:

| Funktion | Online | Offline |
| --- | --- | --- |
| Inventar anzeigen | ✅ | ✅ (gecacht) |
| Einträge bearbeiten | ✅ | ⚠️ (eingeschränkt) |
| Neue Einträge anlegen | ✅ | ❌ |
| Synchronisation | ✅ | ❌ |

> Im Offline-Modus werden zuletzt geladene Daten aus dem Cache angezeigt. Änderungen, die offline gemacht werden, können je nach Gerät verloren gehen – daher empfehlen wir, wichtige Änderungen nur mit aktiver Internetverbindung vorzunehmen.
> 

---

## Updates

Die PWA aktualisiert sich automatisch im Hintergrund, sobald sie mit dem Internet verbunden ist. Nach einem Update wirst du beim nächsten Öffnen kurz benachrichtigt.

Du musst **keine manuelle Aktualisierung** durchführen.

## Tipps für die mobile Nutzung

- **Querformat** auf Tablets gibt mehr Platz für die Inventarliste
- Nutze die **Suchfunktion** statt zu scrollen – spart Zeit auf kleinen Bildschirmen
- Aktiviere **„Zum Startbildschirm hinzufügen"**, damit du RigFlow wie eine echte App öffnen kannst
