# Installation

## Installation – Android

1. Öffne die RigFlow Web App in **Google Chrome** (empfohlen).
2. Tippe oben rechts auf das **⋮ Menü** (drei Punkte).
3. Wähle **„App installieren"** oder **„Zum Startbildschirm hinzufügen"**.
4. Bestätige mit **„Installieren"**.
5. RigFlow erscheint jetzt als App-Icon auf deinem Startbildschirm.

> Hinweis: Die genaue Bezeichnung des Menüpunkts kann je nach Chrome-Version leicht abweichen.
> 

---

## Installation – iOS (iPhone / iPad)

1. Öffne die RigFlow Web App in **Safari** (andere Browser unterstützen PWA-Installation auf iOS nicht vollständig).
2. Tippe unten auf das **Teilen-Symbol** (Quadrat mit Pfeil nach oben).
3. Scrolle nach unten und wähle **„Zum Home-Bildschirm"**.
4. Passe den Namen an (optional) und tippe auf **„Hinzufügen"**.
5. RigFlow erscheint als Icon auf deinem Home-Bildschirm.
