# RigFlow Docs

> RigFlow ist eine moderne Gear- & Equipment-Management-App für Veranstaltungstechnikerinnen und -techniker. Damit verwaltest du dein gesamtes Equipment-Inventar, planst Einsätze und behältst den Überblick – egal ob am Rechner, im Browser oder auf dem Smartphone.

---

## Was ist RigFlow?

RigFlow hilft dir dabei, dein technisches Equipment strukturiert zu verwalten. Ob Mikrofone, Lautsprecher, Kabel, Lichttechnik oder Spezialgeräte – mit RigFlow hast du immer im Blick, was verfügbar ist, was gerade im Einsatz ist und was gewartet werden muss.

Die App ist auf **drei Plattformen** verfügbar:

| Plattform | Beschreibung | Link |
| --------- | ------------ | ---- |
| 🌐 **Web App** | Vollständige App im Browser – immer aktuell | [Erste Schritte](/docs/erste-schritte) |
| 🖥️ **Desktop App** | Windows-Anwendung (Electron) für Offline-Nutzung | [Desktop App](/docs/Desktop/desktop-app) |
| 📱 **PWA / Mobile** | Installierbar auf Android & iOS | [PWA / Mobile](/docs/PWA/pwa-mobile) |
|  |  |  |
