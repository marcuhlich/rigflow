# Features

Das Inventar-System ist das Herzstück von RigFlow. Hier verwaltest du all dein Equipment – von Kameras über Objektive bis hin zu Zubehör.
Deshalb hier eine Übersicht aller Funktionen, die RigFlow bietet – von der Inventarverwaltung bis zur plattformübergreifenden Nutzung.

---

## Inventarverwaltung

Das Herzstück von RigFlow. Hier verwaltest du dein gesamtes Equipment.

### Einträge & Felder

Jeder Equipment-Eintrag kann folgende Informationen speichern:

| Feld | Beschreibung |
| --- | --- |
| Name | Bezeichnung des Geräts |
| Kategorie | Zuordnung zu einer Geräteklasse |
| Seriennummer | Eindeutige Kennung (optional) |
| Menge | Anzahl verfügbarer Einheiten |
| Status | Verfügbar / Im Einsatz / In Wartung |
| Notizen | Freitext für Zustand, Besonderheiten etc. |

### Suche & Filter

- Volltextsuche über alle Felder
- Filter nach Kategorie, Status oder Schlagwort
- Sortierung nach Name, Datum oder Status

---

## Ausleihe & Einsatzplanung

Mit RigFlow kannst du Equipment für Veranstaltungen reservieren und verwalten, was gerade wo im Einsatz ist.

- **Equipment einem Event zuweisen** – Verknüpfe Geräte mit konkreten Veranstaltungen
- **Rückgabe erfassen** – Status wird automatisch auf „Verfügbar" gesetzt
- **Übersicht offener Ausleihen** – Sofort sehen, was noch unterwegs ist

## Releases & Updates

RigFlow aktualisiert sich automatisch. Neue Versionen werden über **GitHub Releases** ausgeliefert:

- 🌐 **Web App**: Aktualisiert sich beim nächsten Seitenaufruf automatisch
- 🖥️ **Desktop App**: Zeigt beim Start eine Benachrichtigung, wenn ein Update verfügbar ist → [Desktop App](/docs/Desktop/desktop-getting-started)
- 📱 **PWA**: Aktualisiert sich bei einer Internetverbindung im Hintergrund → [PWA / Mobile](/docs/PWA/pwa-getting-started)
