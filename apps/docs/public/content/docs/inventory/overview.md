# Inventar Übersicht

Das Inventar-System ist das Herzstück von RigFlow. Hier verwaltest du all dein Equipment – von Kameras über Objektive bis hin zu Zubehör.

## Kernfunktionen

### Equipment-Kategorien

Organisiere dein Equipment in **Kategorien**:

- 📷 **Kameras** – Bodies, Gehäuse
- 🔭 **Objektive** – Festbrennweiten, Zooms
- 💡 **Licht** – LEDs, Blitze, Softboxen
- 🎤 **Audio** – Mikrofone, Recorder
- 🔧 **Zubehör** – Stative, Filter, Kabel

### Status-Tracking

Jedes Item hat einen Status:

```
verfügbar → reserviert → ausgeliehen → zurückgegeben
```

### Standort-Verwaltung

Verfolge Equipment über verschiedene Standorte:

- **Lager** – Hauptstandort
- **Set** – Aktiv im Einsatz
- **Transport** – Unterwegs
- **Wartung** – In Reparatur

## Best Practices

> 💡 **Tipp:** Nutze QR-Codes für schnelles Check-in/Check-out. Das spart Zeit und minimiert Fehler.

1. Benenne Items konsistent
2. Füge immer Seriennummern hinzu
3. Mache Fotos beim Check-out
4. Setze Wartungsintervalle
