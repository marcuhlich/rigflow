# Erste Schritte mit RigFlow

Willkommen bei **RigFlow** – deiner modernen Lösung für Equipment-Management und Inventarverwaltung.

## Installation

```bash
# App herunterladen
https://rigflow.app/download

# Oder via Package Manager
npm install rigflow-cli
```

## Schnellstart

1. **Account erstellen** – Registriere dich auf [rigflow.app](https://rigflow.app)
2. **Team einrichten** – Lade dein Team ein und weise Rollen zu
3. **Equipment hinzufügen** – Scanne QR-Codes oder trage Items manuell ein
4. **Loslegen** – Verwalte dein Equipment in Echtzeit
